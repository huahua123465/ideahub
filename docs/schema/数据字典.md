# IdeaHub 数据字典

由 `information_schema` 直接生成，不是手写的 —— 和线上库一定一致。
完整建表语句见同目录 `ideahub-schema.sql`（可直接 `psql -f` 建一套空库）。

- 数据库：PostgreSQL 16
- 库名 / 用户：`ideahub`
- 共 27 张表

## 枚举类型

| 类型 | 取值 |
|---|---|
| `client_stage` | `lead` · `wechat` · `profiled` · `consulted` · `coaching` · `renewed` · `lost` |
| `idea_status` | `draft` · `pending` · `reviewing` · `adopted` · `rejected` · `archived` |
| `user_role` | `member` · `reviewer` · `admin` |
| `work_channel` | `persona` · `matrix` · `live` |
| `work_side` | `own` · `benchmark` |
