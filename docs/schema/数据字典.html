动手之前先看这张图

标签和关联这两件事不是靠外键实现的，写 join 的时候会踩坑。先看清楚它们怎么指过来的。

写查询时最容易踩的三个坑：

① entity_tags / links 只按 entity_id join 会串表，必须同时限定 entity。

② ideas 和 demands 是软删，统计时要加 WHERE deleted_at IS NULL，否则会数进已删除的记录。

③ ideas 一张表同时是灵感池和正式库：status IN ('pending','reviewing') 是灵感池，status = 'adopted' 才是正式库。

拿到结构的两种方式

# 一、直接建一套一模一样的空库（只有结构，没有任何数据）
createdb ideahub_copy
psql -d ideahub_copy -f ideahub-schema.sql

# 二、在服务器上重新导一份最新的
cd /root/ideahub-deploy
docker compose exec -T db pg_dump -U ideahub -d ideahub \
  --schema-only --no-owner --no-privileges > 结构.sql
