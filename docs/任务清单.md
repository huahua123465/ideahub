- [x] **T0 项目框架**
  目录结构、README、package.json、.env.example、.gitignore、任务清单、进度记录
  验证：目录建全，`node -e "1"` 能跑

- [x] **T1 数据库层**
  `schema.sql` 建表 / `db/pg.mjs` 生产驱动 / `db/psql.mjs` 免安装备用驱动 / `db/index.mjs` 统一出口

## 阶段二：后端

- [x] **T3 HTTP 骨架**
  `index.mjs` 入口、`router.mjs` 极简路由、`lib/http.mjs` 请求响应工具、静态文件托管、健康检查
  验证：`curl /api/health` 返回 200

- [x] **T4 灵感读写 API**
  `GET /api/ideas`（分页/筛选/排序）、`GET /api/ideas/:id`、`POST /api/ideas`、`PATCH /api/ideas/:id`
  验证：脚本跑一遍增查改

- [x] **T5 投票与评论 API**
  `POST /api/ideas/:id/vote`（唯一主键防重复）、`POST /api/ideas/:id/comments`
  验证：同一用户连投两次，票数只加 1

- [x] **T6 状态流转 API**
  `PATCH /api/ideas/:id/status`，行级锁 + 状态机校验 + 生成正式编号 + 写审计流水
  验证：并发两次采纳，只有一次成功；否决不填理由被拒

- [x] **T7 统计与查重 API**
  `GET /api/stats/overview`、`GET /api/ideas/similar`、热度重算
  验证：统计数字与直接 SQL 聚合一致
