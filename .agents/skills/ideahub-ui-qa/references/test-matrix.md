# IdeaHub UI 验收矩阵

## 通用基线

`npm run test:ui` 固定检查：

- 内存生产 bundle 可以构建。
- 今日工作台与全局导航可用。
- 项目功能树、灵感池、正式库、统计、样本库、学习中心和内容采集可打开。
- 提交灵感弹窗在桌面和手机视口内完整出现。
- 1440×900 与 390×844 没有页面级横向溢出。
- 移动导航维护 `aria-expanded` 并在跳转后关闭。
- reduced motion 媒体条件可用。
- 浏览器没有未处理异常或 console error。

产物位于 `scripts/.uidiff/`：

- `report.json`：bundle 大小、结构断言、溢出测量、截图清单和浏览器错误。
- `*-desktop-1440x900.png`：桌面证据。
- `*-mobile-390x844.png`：手机证据。

## 按改动追加检查

| 改动范围 | 追加检查 |
|---|---|
| 导航、全局顶栏、搜索 | 桌面与移动导航；当前项 ARIA；搜索清空与快速输入 |
| 灵感池、弹窗、附件 | `npm run test:idea-files`；上传失败输入保留；弹窗滚动 |
| 样本库与研究 | `npm run test:samples` 或对应 stage；宽表局部滚动；手机卡片替代 |
| Collector | `ideahub-collector` 中的代理、compose、archive UI 与 VPS smoke |
| 学习中心/PDF | 连续翻页、缩放、全屏、手机安全区和 PDF worker |
| 异步筛选与 tab | 慢响应、快速来回点击、旧请求不得覆盖最后选择 |
| 全局 CSS/tokens | 至少复看首页、灵感池、样本库和一个弹窗，确认没有跨页面污染 |

## 截图人工检查

截图复核至少回答：

1. 页面主次是否一眼清楚。
2. 文案有没有截断、重叠或不自然换行。
3. 按钮和状态反馈是否靠近触发操作。
4. 手机端是否把宽表、工具栏和弹窗合理重排。
5. 新元素是否沿用现有颜色、圆角、阴影、字体和间距语言。
