# 创作者内容采集台：功能结构

```text
分享链接 / 分享文案
        │
        ▼
完整归档（固定默认）
        ├── 下载并长期保留原图 / 视频 / 音频
        └── 执行 OCR / 语音转写 / 结构化分析
        │
        ▼
平台识别（抖音 / 小红书）
        │
        ├── 账号基础数据
        │   ├── 账号名称
        │   ├── 主页链接
        │   ├── 简介
        │   ├── 关注量
        │   ├── 粉丝量
        │   └── 获赞与收藏量（抖音返回获赞量）
        │
        ├── 内容数据
        │   ├── 标题 / 描述 / 话题
        │   ├── 正文 / 原图
        │   ├── 图片与视频 OCR
        │   ├── 语音转写
        │   └── 点赞 / 收藏 / 评论
        │
        └── 互动数据
            ├── 高赞评论 Top 5
            ├── 评论回复
            └── 扫描覆盖与置信度
        │
        ▼
AI 业务分析（两项独立、可降级）
        ├── 视频 / 内容分析
        │   ├── 主要内容
        │   ├── 人群 / 场景
        │   ├── 问题 / 需求
        │   ├── 内容结构
        │   ├── 解决办法
        │   ├── 值得参考
        │   └── 延伸内容
        └── 评论需求分析
            ├── 主要问题 / 高频需求 / 担忧 / 未讲清点
            ├── 值得重点看的评论
            └── 延伸选题 + 可回看的代表评论原话
        │
        ▼
结果工作区
        ├── AI 分析与评论证据定位
        ├── 账号卡片
        ├── 内容卡片与画廊
        ├── 复制全部
        └── JSON / Markdown / TXT 导出
```

## 数据完整性规则

- 只使用平台页面、页面内嵌结构化状态或下载器明确返回的字段。
- 主页结构化状态优先于帖子摘要；帖子摘要仅用于补齐空字段。
- 平台未返回的账号字段统一保存为空字符串，不通过其他指标估算。
- 小红书的 `interaction` 对应“获赞与收藏量”；抖音的 `total_favorited` 对应“获赞量”。
- 所有新任务均使用完整归档：原图、视频和音频保存在任务目录，并在删除任务时一并移除。
- AI 视频分析与 AI 评论分析分别执行；任一项失败不会丢失原始数据或另一项分析。
- 评论分析只让模型返回评论 ID，页面展示的代表性原话由后端从已采集评论回填，模型不能改写证据。
