报销单

报销审批设置

报销单按「部门负责人 → 总经理 → 财务 → 出纳」流转，小额单子可以免掉总经理这一步。没选负责人的部门暂不启用，可以分几次配完；人员有变动时改这里，审批中的单子会自动转给新的人。这里的设置采购也在用。
部门与部门负责人
小额免总经理审批
金额不超过额度的单子自动跳过总经理这一步，其余各步照走。留空用默认值；填 0 表示都要过总经理。

导出报销记录

导出成 Excel / WPS 双击就能打开的表格。「单据明细」每张报销单一行；「审批记录」列出每一步谁在什么时间做了什么、写了什么意见，以及每次上传的附件。

修改密码

改完之后，其它设备上的登录状态都会失效，需要重新登录。
